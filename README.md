# School of IT Skills - MSDC Course Catalogue

A premium, modern course-catalogue website for School of IT Skills at Manipal Skill Development Centre (MSDC), Manipal.

The platform is built for clarity, speed, and trust:

- clean navigation across all programs
- strong visual hierarchy and accessible layouts
- rich interactions and multiple themes
- dedicated pages for each learning track
- detailed course pages with outcomes, curriculum, and audience fit

## About School of IT Skills and MSDC

School of IT Skills is a flagship IT learning initiative under Manipal Skill Development Centre (MSDC), a unit of Dr TMA Pai Foundation.

The mission is simple: empower learners with practical, job-ready digital skills through structured, mentor-led training that combines concepts, labs, projects, and career orientation.

## Program Tracks

The catalogue currently includes 30 programs across four tracks:

| Track | Count | Focus |
| --- | ---: | --- |
| Professional Programs | 15 | Career-grade IT upskilling for students and working professionals |
| Tally Suite | 5 | Official Tally Prime accounting, taxation, and compliance pathways |
| Internship Programs | 4 | Project-based mentor-led internships |
| For School Children | 6 | AI and coding foundations for Class 6 to 12 |

### Popular domains covered

- Data Analytics and Visualization (Power BI, Python)
- Full Stack Development
- Python Programming
- AI and ML
- Cyber Security
- SQL and DBMS Optimization
- Tally, GST, and Taxation
- Kids AI and Python Labs

## Website Pages

This project includes dedicated pages for major discovery and conversion flows:

- About
- Contact

## Experience and Design Direction

The UI is intentionally premium and interactive:

- floating navbar with active-link feedback
- magnetic buttons and reveal interactions
- marquee and animated visual accents
- card depth, glow corners, and subtle motion
- multi-theme support for brand expression
- responsive layout for desktop and mobile

## Tech Stack

- React 19
- TanStack Router and TanStack Start
- TypeScript
- Vite 8
- Tailwind CSS 4
- Radix UI primitives
- Lucide React icons

## Content Architecture

Core content and metadata are maintained in:

- src/data/courses.ts
- src/data/course-detail.ts

These files power:

- track-wise listing
- individual course pages
- curriculum modules
- outcomes, tools, prerequisites, and FAQs

## Local Development

### Prerequisites

- Node.js 20+
- npm 10+

### Run locally

```bash
git clone <your-repository-url>
cd schoolofitskills
npm install
npm run dev
```

Open the local URL shown in terminal after Vite starts.

### Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
npm run format
```
